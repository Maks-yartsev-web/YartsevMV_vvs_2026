## 📂 Структура проекта

### homewor1 — Калькулятор (Эволюция кода)
Цель работы — показать, как одна и та же задача (калькулятор) решается с помощью разных подходов программирования:
*   Линейный код (последовательное выполнение).
*   Разделение логики на отдельные функции.
*   Использование единой функции с циклом `while`.
*   Объектно-ориентированный подход (реализация через класс).

### homework2 — Работа со строками
Интерактивный тренажер для изучения методов обработки текста. 
*   Состоит из 5 уровней, на которых разбираются методы изменения регистра, поиска и замены подстрок.
*   Финальный этап — написание скрипта-редактора, который автоматически очищает текст от лишних пробелов и корректно расставляет знаки препинания.

### homework3 — «Лабиринт»
Консольная RPG-игра на Python.
*   **Геймплей:** генерация карты, постепенное открытие локаций (туман войны), сражения с монстрами, обход ловушек и поиск выхода.
*   **Инвентарь:** продвинутая система хранения и взаимодействия с предметами (сортировка, применение зелий к оружию).
*   **Особенность:** в коде наглядно продемонстрирована разница между поверхностным (`copy`) и глубоким (`deepcopy`) копированием объектов при работе с инвентарем.

### homework4 — «Титаник»
Практика по анализу табличных данных с использованием **Pandas** и **NumPy**.
*   **Предобработка:** изучение структуры датасета, выявление и заполнение пропусков (медианой), удаление неинформативных столбцов.
*   **Анализ:** фильтрация данных по сложным условиям, группировка (`groupby`), расчет статистики выживаемости по полу, классам и портам посадки.
*   **Результат:** экспорт очищенных данных и сводных таблиц в новые CSV-файлы.
